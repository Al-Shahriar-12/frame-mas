# Example frames

Open any of these in Frame MAS with **Model → Project → Open file**. Each comes with BNBC 2020 strength combinations and a D + L service combination; regenerate them for another code in **Model → Loads**.

| File | What it shows |
| --- | --- |
| `two-storey-two-bay-frame.frmas` | Fixed-base building frame with dead, live and wind cases |
| `portal-frame.frmas` | Single-bay portal on pinned bases under gravity and wind |
| `gable-portal-frame.frmas` | Pitched portal with wind on a column and normal pressure on a rafter |
| `pratt-truss.frmas` | Six-panel Pratt truss with truss members and joint loads |
| `three-hinged-frame.frmas` | Statically determinate frame with a hinge at mid-span |
